# 남산 하늘숲길 나들이 가이드

스마트폰과 PC에서 보는 남산 나들이 안내 페이지입니다.

## 게시 주소

https://crus7230.github.io/pp_random/

## 파일과 기능

- `index.html`: 코스 안내, 확대 가능한 SVG 안내 지도, 정류장 위치와 버스 운행정보 링크, 준비물 체크리스트입니다.
- `.nojekyll`: HTML을 그대로 게시하도록 설정합니다.
- `.gitignore`: 로컬 환경 설정과 백업 파일을 게시 대상에서 제외합니다.

지도는 코스를 설명하는 안내도입니다. 정류장의 실제 위치와 도착정보는 페이지의 네이버·구글지도 및 공식 교통정보 링크에서 확인합니다.

## 실행과 수정

`index.html`을 수정하고 `main` 브랜치에 반영하면 GitHub Pages가 다시 게시합니다. 게시 설정은 `main` 브랜치의 `/` 폴더입니다.

로컬 미리보기:

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

외부 스타일·아이콘·폰트와 교통정보 링크를 사용하므로 인터넷 연결이 필요합니다. API 키, `.env`, PC 전용 타일 서버는 포함하지 않습니다.
